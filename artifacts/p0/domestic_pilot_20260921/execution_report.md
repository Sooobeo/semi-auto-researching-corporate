## 실제 진행 범위

기존 공시·IR 기본 40건과 공식 영문 Newsroom 4건·186블록은 입력 기준으로 보존했다. 기존 본문을 재감사하거나 국내 언론사 검증 결과로 전환하지 않았다. 삼성 메모리와 DS/전사, SK 연결/제품 범위도 유지했다. 기준 사건 기간은 2024Q1~2026Q2이며 기사 발행일 필터와 동일하지 않다.

- [권리 조사](rights_review.md): 공개 공식 문서 고유 URL 19개, 조사 기록 24건(성공 17·실패 6·부분 1). 상품설명·약관의 조회 결과이며 기사/API 접근 성공률과 분모가 다르다.
- [공식 발표 후보](official_anchors.csv): 잠정 family 13개(SAM 6, SKH 7). 기존 doc/revision 연결 6개, 신규 공식 검색 메타데이터 후보 7개. 신규 본문 근거 span 검증은 0개다.
- [표집 격자](sampling_matrix.csv): 16칸 중 13칸 선정. 삼성 앞 시기 투자, 삼성 뒤 시기 개발, SK 뒤 시기 투자의 3칸은 `not_yet_checked`이며 실제 발표 부재를 뜻하지 않는다.
- [검색 기록](discovery_metadata.json): 18개 검색 배치에서 링크 관측 276회, 고유 URL 258개. 목록·증권사 PDF·모바일/AMP 변형·시기 외 결과도 보존했으므로 258개를 기사 수로 세지 않는다. 기사 본문·검색 패시지는 파일에 저장하지 않았다.

## 권리 확인 결과와 현재 제한

[NewsStore AI 상품](https://www.newstore.or.kr/store/prodct/ainewsdata/list.do)에 1차 후보 8개 매체가 모두 등재된 것은 확인했다. 본 프로젝트의 구매·승인 계약, 실제 발행일별 제공 범위와 API 응답은 확인하지 않았다. 상품 안내의 AI 학습 허용을 개별 이용권으로 간주하지 않았으며 기사 본문 대외전송 제한도 별도로 기록했다.

[분석용 상품](https://www.newstore.or.kr/store/prodct/newsdata/list.do)은 AI 활용 불가다. [BIGKinds FAQ](https://www.bigkinds.or.kr/news/faqList.do?page=2)의 무료 다운로드 본문은 첫 200자이며, 실제 검색화면의 접근 실패도 남겼다. 따라서 이번 기사 후보 발견은 BIGKinds의 모집단·분포 검증 결과가 아니라 일반 공개 웹 검색의 제목·URL 결과다.

[SK 영문 뉴스룸 약관](https://news.skhynix.com/en/terms-of-use/)의 자동 접근 금지에 따라 신규 본문 자동 접근을 실행하지 않았다. 한국어·영문 도메인의 조건은 따로 기록했다. 직접 언론사 8개 사이트의 본문 이용조건은 별도 미확인으로 남겼으며, NewsStore 판매 목록에 있다는 이유로 직접 수집을 허용하지 않았다.

본문 수집·분석 가능한 프로젝트 권한이 확인되지 않아 국내 기사에 대한 직접 본문 요청, 원문 저장, 추출, AI 분석은 모두 미실시다. 계약 존재 여부 자체는 아직 확인되지 않았으며 계약이 없다고 단정하지 않는다. [공급사 문의 초안](supplier_questions.md)은 준비했지만 외부 발송·구매·회원가입은 하지 않았다. NAVER API는 현행 제외 상태다.

## 구현과 검증

기존 `p01_news_body_crawl.py`와 기존 고정 회귀 검증기를 국내 매체에 확대 실행하지 않았다. 새 [후보 준비 도구](../../../scripts/p01_prepare_domestic_metadata.py)와 [권리 검사·수집·감사 도구](../../../scripts/p01_domestic_pilot.py)를 추가했다. 후자는 계약 API adapter가 아닌 인증 없는 정적 HTML용이며, 이번 실데이터 실행은 네트워크 없는 `gate`와 `audit`에 한정한다.

수집은 새 출력 경로만 허용하고 원본·실패·수정본을 보존한다. 각 redirect 목적지의 도메인·약관·권리·robots를 요청 전에 검사한다. 호스트 간격, 429/Retry-After 대기, 403·paywall 중단을 적용한다. XPath 위치와 Unicode code point 일치는 원문 완전성이나 문장/청크 gold와 별개다. 원문과 민감할 수 있는 최종 URL provenance는 Git 제외 경로에 둔다.

실데이터 실행 결과 [gate manifest](gate_001/manifest.csv)의 39행 모두 `deferred_rights_rights_not_verified`다. [입력 manifest 기반 감사](audit_001/audit.json)는 무결성 통과·오류0이며 본문 성공률/추출률은 분모0의 NA다. 이 통과는 본문 품질 통과가 아니다.

구현 담당이 네트워크 없는 synthetic fixture 테스트 24개를 실행해 통과했다. 미확인 권리, 계약/공개허락 근거·유효기간, redirect별 권리/robots, 403, 429/Retry-After, 덮어쓰기 거절, 원문 해시·Unicode offset·XPath, 최종URL provenance 및 저장-시도 상태 모순을 검사했다. 실제 언론사 본문에 대한 추출 성능은 검증하지 않았다.

[최종 무결성 확인](final_validation.json)에서 기존 보호 입력12개가 모두 원래 해시와 같고, 기존 원문 manifest 참조46개(고유 doc_id44개)가 기록된 원문 해시와 일치했다. 의도된 기존 파일 변경은 `.gitignore` 한 개다. 신규 13family/16칸/39후보·링크, 3매체/family, 사람검토40슬롯, 누락 날짜·미실시 라벨, Git 원문 제외, diff 형식 점검도 오류0이다.

실행 명령·입력 버전은 [run manifest](run_manifest.json), 산출물 해시는 [체크섬 목록](artifact_checksums.csv)에 기록한다. 전체 파일럿 완료 판정은 본문·사람 감사가 끝날 때까지 보류한다.

## 이어서 진행할 조건

1. 보유 계약/승인 문서가 있다면 실제 매체·발행기간·저장·로컬 분석·AI·외부 전송 범위를 확인한다. 없거나 불명확하면 문의 초안의 내용으로 공급사 확인을 준비한다.
2. 승인된 파일/API 소표본을 받으면 원시 응답과 수정본을 허용된 위치에 보관한다. NewsStore API는 실제 계약·응답에 맞춰 별도 adapter를 검증한다.
3. 고정된 39개 후보를 먼저 시도하고 실패·중복을 유지한다. 제목/리드/본문·인용·날짜·scope·숫자 원문 감사와 첫 20건의 사람 두 명 검토를 진행한다.
4. 동일 주장·화자·장르·기사 위치를 맞춘 구간에서 표현과 정보 선택을 분리해 비교한다. 통계적 매체 문체 일반화는 하지 않는다. 100+20 기사 확대와 온톨로지는 이번 범위 밖이다.
