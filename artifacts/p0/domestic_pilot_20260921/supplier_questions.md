# NewsStore 샘플·견적·권한 확인 문의 초안

상태: **검토용 초안 / 미발송** (2026-09-21). 외부 연락·구매·회원가입·로그인은 수행하지 않았다. 이미 보유한 계약/승인서가 있다면 먼저 검토하여 아래 중 미확인 항목만 질의한다.

수신 경로는 [공식 AI 뉴스데이터 페이지](https://www.newstore.or.kr/store/prodct/ainewsdata/list.do)의 견적/데이터 구매 담당 안내를 사용한다. 이 파일은 발송 승인이 아니다.

## 제목

기업뉴스 연구용 AI 뉴스데이터: 8개 매체 기간·샘플·처리권한 및 견적 확인

## 문의 내용

삼성전자 메모리 사업과 SK하이닉스에 관한 국내 한국어 보도를 연구하려고 합니다. 공식 기업 발표를 기준으로 동일 주장에 대한 기사 표현·인용·정보 선택을 비교하는 소규모 접근성 파일럿입니다.

초기 후보는 독립 발표 묶음 12~20개에 매체별 기사 3개씩, 총 36~60개이며 실제 확보량은 아직 정해지지 않았습니다. 사건의 기준 기간은 2024Q1~2026Q2입니다. **기준 분기와 기사 발행기간은 다릅니다.** 예를 들어 2026Q2 실적 관련 기사는 분기 종료 이후 발표될 수 있습니다. 제공 가능 발행기간·기간 산정 방식과 필요한 후속/정정기사 포함범위를 아래처럼 별도로 확인하고 싶습니다.

1. **매체별 제공 범위와 샘플**
   - 매일경제, 한국경제, 전자신문, 디지털타임스, 이데일리, 뉴스핌, EBN, 지디넷코리아 각 매체의 AI 상품 제공 가능 여부와 원문 발행일 기준 시작/종료일을 알려주십시오.
   - 2024Q1~2026Q2 관련 발표일 주변 기사 및 후속·정정 기사에 대해 조회 가능 기간과 누락 기간이 있는지 확인 부탁드립니다.
   - 제공 가능한 상품은 학습·파인튜닝용, RAG용, 또는 연구 분석용 중 어느 것인지, 게시된 RAG 구매 준비중 안내의 현재 상태는 무엇인지 알려주십시오.
   - 권리 검토와 완전성 확인을 위한 승인된 소표본을 요청드립니다. 실제 sample 이용범위/보유기간도 명시해 주십시오. 무료 웹페이지의 본문을 대신 수집하지 않습니다.

2. **원문·메타데이터와 버전**
   - 제목, 부제, 리드, 본문, 소제목, 표, 인용, 바이라인 및 원문 URL이 어느 필드로 제공되는지 알려주십시오. 첫 200자 상품과 Full Text를 구분해 주십시오.
   - news_id, provider_news_id, provider, content, published_at, enveloped_at, dateline의 의미·타임존·누락 처리와 수정일/정정일 필드를 확인하고 싶습니다.
   - 같은 URL 수정본을 다시 받을 수 있는지, 정정·삭제 기사와 전재·번역 기사를 어떤 ID/관계로 제공하는지 알려주십시오.
   - HTML/NewsML/JSON 원본과 기사 내 문단 경계·표 구조·인용 구분을 보존하는지 알려주십시오. 일반 샘플 기술문서와 실제 계약 반환 필드가 다른지도 확인 부탁드립니다.

3. **각 사용행위의 허용 범위**
   아래 항목 각각을 허용/불가/조건부로 답변하고 계약 조항 또는 별도 승인 범위를 부탁드립니다.
   - API 자동 조회·파일 다운로드, 제목/URL 등 메타데이터 저장, 기사 원문 저장
   - 내부 비상업 연구/통계 분석과 로컬 NLP/형태소 분석
   - 로컬 LLM 입력·평가, 모델 학습/파인튜닝
   - 원문을 제3자 클라우드 LLM 또는 embedding API에 입력하는 처리
   - 자체 환경의 embedding/vector 생성·저장, 원문 일부가 포함된 문장/청크 저장
   - 분석 통계·라벨·짧은 근거 구간 및 원문 링크의 외부 공개
   - 내부 공동연구자의 열람·공유, 외부 협력기관 공유, 원문/파생데이터 재배포
   공개 AI 상품에는 뉴스 본문 대외전송 제한이 있으므로, 외부 모델 입력을 기본 허용으로 해석하지 않습니다. 외부 처리가 가능한 예외가 있다면 처리자·지역·보유/학습금지·삭제 조건까지 명시해 주십시오.

4. **보관·종료·정정**
   - 원문, 메타데이터, vector, chunk, 백업 각각의 보유기간과 계약 종료/해지 후 삭제 또는 연구재현 보관 조건은 무엇입니까?
   - 논문·내부 보고서·모델 평가의 재현을 위해 hash, 원문 위치, 짧은 인용을 유지할 수 있습니까?
   - 원저작자의 삭제/정정 요청, 라이선스 철회 및 매체 계약 변경 때 통지·삭제 대상과 소요기간은 무엇입니까?
   - 이용 가능한 저장 위치, 접근 가능한 연구자 수와 별도 보안 요건을 알려주십시오.

5. **API 운영 및 견적**
   - 인증 방식, 요청/일별 quota, 초당 한도, pagination, 기간별 검색 제한, 오류 코드·429·Retry-After·재시도 지침을 부탁드립니다.
   - 동일 기사 재조회·수정본·중복 응답과 다운로드가 과금 건수에 포함되는지 알려주십시오.
   - 소표본 36~60개 기사 파일럿과 이후 확대를 분리한 최소 구매량·과금 단위·가격 및 부가세를 제시해 주십시오.
   - 학술/비영리 요건에 필요한 기관·연구계획서 등 증빙을 알려주십시오. 연구주체/소속/담당자 정보는 실제 발송 시 기입하겠습니다.

회신은 매체 × 제공기간 × 사용행위별로 확인 가능하도록 계약안·허용범위표와 함께 부탁드립니다.

## 첨부/회신 후 처리

- 후보 목록은 최종 선택된 기사 URL·발표일 창만 첨부하고 기사 원문은 보내지 않는다.
- API 키·토큰은 문서/이메일에 요청하거나 붙여 넣지 않고 공급사가 안내한 안전한 발급 경로를 이용한다.
- 회신을 받으면 source_registry에서 공개 상품설명과 개별 승인 증거를 분리한 채 갱신한다. 권한이 확인된 소표본만 수집·추출·감사한다.
- BIGKinds 기관 API를 별도 검토할 때는 기관자격, 실제 협약기간, 무료 export와 차이, 완전본문 제공성 및 같은 사용행위 표를 추가 확인한다. 기존 문서의 최대12개월 설명을 현행 확인값으로 제시하지 않는다.
