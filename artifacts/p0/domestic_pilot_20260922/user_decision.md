# P01 비상업 연구 표본 실행 지시

2026-09-22 사용자가 “그냥 그대로 진행해 상업적으로 쓰일거 아니라서 괜찮아”라고 지시했다. 이에 따라 2026-09-21에 고정한 39개 기사 후보에 한해 권리 미확정 상태 자체를 일괄 중단 사유로 삼지 않고 공개 접근·로컬 수집·추출 시험을 진행한다. 온톨로지는 계속 제외한다.

이는 사용자의 실행 지시를 기록한 것이며 출처가 이용허락을 했거나 법률상 적법성이 확정되었다는 기록이 아니다. source_registry의 unresolved를 allowed/verified로 바꾸지 않는다. 실제 출처의 명시적 수집 금지, robots 차단, 403·유료벽 등은 후보별 결과로 보존한다. 접근 실패를 다른 후보로 교체해 성공률을 높이지 않는다.

실행 범위는 research_authorization.json의 후보 ID·원 URL·출처·도메인으로 고정한다. 원문 및 원문 구간이 포함된 결과는 Git 제외 raw/ 경로에 보관하고 공유 문서에는 식별자·해시·위치·검토 결과만 남긴다. 학습·재배포 작업은 수행하지 않는다. 사람 두 명의 검토와 자동/에이전트 점검을 구분한다.

2026-09-21의 보류 manifest와 보고서는 수정하지 않는다. 이번 실행은 새 디렉터리에 기록하며, 같은 doc_id의 원문 수집본은 hash 기반 revision으로 연결한다. 계약이 확인된 경우를 위한 기존 strict 실행 경로도 유지한다.
