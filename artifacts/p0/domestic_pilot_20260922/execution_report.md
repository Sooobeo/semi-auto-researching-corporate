# P01 국내 뉴스 수집·추출 실행 결과

2026-09-22. 이전에 고정한 기사 후보 39개를 유지한 채, **국내 언론사 3곳의 기사 HTML 22개를 수집하고 본문 위치 검증·규칙 분할·비교 후보 생성을 실행했다.** 같은 잠정 발표 family의 기사 9쌍 중 8쌍에서 문장 비교 후보 48쌍을 만들었다. 온톨로지는 이번 작업에 포함하지 않았다.

## 실행 근거와 범위

사용자의 비상업 연구 진행 지시를 [실행 기록](user_decision.md)과 [고정 후보 정책](research_authorization.json)에 기록했다. 미확정 권리를 일괄 중단 사유로 삼던 이전 실행과 별도로 새 경로에서 진행했다. 출처의 이용허락 상태 `unresolved`와 사용자 실행 근거 `user_noncommercial_research`는 별도 필드로 유지한다. 소표본 로컬 수집·규칙 처리이며, 학습·외부 LLM 본문 전송·원문 재배포는 수행하지 않았다.

연구 대상 기준 기간은 **2024Q1~2026Q2**다. 수집된 22개 기사에서 추출한 게시 날짜 후보는 **2024-02-27~2026-04-30**에 분포한다. 기준 분기, 공식 발표일, 기사 게시·수정시각, 수집시각을 구분했다. 삼성전자 메모리와 DS/전사, SK하이닉스 연결/제품 scope는 기사별 미검증 상태를 보존했다. 기사에 기준 사건의 scope·기간을 그대로 복사해 확정하지 않았다.

출처 조건은 [source_review.md](source_review.md)와 [source_registry.csv](source_registry.csv)에 기록했다. 한국경제 10개와 뉴스핌 7개 후보는 명시적 자동수집 금지에 따라 기사 요청 없이 제외 기록을 남겼다. 나머지 22개는 공개 URL에 고정 UA와 호스트 간격 3초를 적용해 요청했다. 접근 실패 후보를 다른 기사로 교체하지 않았다. NAVER는 제외 상태이며 NewsStore 계약/API를 사용한 결과가 아니다.

## 본문·날짜·문장 처리

최종 추출 결과는 [body_audit_003](body_audit_003/summary.json)이다. 최초 수집기의 위치 없는 fallback 결과는 근거 span으로 쓰지 않고, 저장 HTML을 매체별 DOM에서 다시 읽었다. 전자신문·지디넷은 `#articleBody`, 이데일리는 `.news_body[itemprop=articleBody]`를 사용했다. 광고·관련기사 위젯 제외 위치와 원문 tail을 보존했다.

- 조립 본문 33,439 code point, DOM text/tail 원자 669개.
- 원본 XPath 재조회와 원문/조립 본문 offset 왕복 **22/22 통과**. 선택 DOM 문자 회계 차이 0.
- 규칙 문장 후보 **448개**, 인용·숫자·단위·기간·회사 등 규칙 span **1,233개**.
- UTF-8 22개, 대체문자 U+FFFD 0개. 제목 검색 메타데이터와의 문자 유사도 최솟값 약 0.814.
- 게시 날짜 후보는 22개 문서 모두 공통 정밀도에서 양립했다. 수정 날짜 후보가 있는 문서는 12개다. 시간대 미상은 그대로 남겼으며 초/분 표기 차이를 충돌로 세지 않았다.
- `CAND-d6ef03257775547f`의 지디넷 본문은 346자로 짧은 본문 검토 신호가 있다. 짧은 속보인지 누락인지 확정하지 않았다.

DOM 내부의 모든 문자를 설명할 수 있다는 것과 기사 전체의 제목·부제·리드·표·인용을 완전히 추출했다는 것은 별개다. 수동 원문 감사, 본문 precision/recall, 문장 경계 F1은 측정하지 않았다. HTML comment 처리 오류가 남은 `body_audit_001`, 시간 표기 차이를 충돌로 과잉 판정한 `002`도 보존했다. 수정 후 `003`을 최종 결과로 지정한다.

공식 anchor의 기존 날짜 충돌 후보 3건은 해결된 것으로 바꾸지 않았다: SK 2024Q1의 4월24/25일, SK 2026Q1의 4월22/23일, 321단 QLC의 2025년8월24/25일. 이번 기사 게시 날짜 검사와 별개다. 숫자의 단위·기간·비교 기준, 삼성 메모리/DS, 개발·검증·양산·출하·판매, 계획/실적 구분도 의미 검토가 필요하다.

## 기사 분류와 표현 비교 산출물

[classification_001](classification_001/README.md)에 기사 분류 39행, 기사–사건 링크 39행, 규칙 신호 39행을 만들었다. 접근 상태와 제목 표식·회사 언급·인용 신호를 기록하고 장르·기원·scope·보도 단계의 사람 판정과 구분했다. 본문 있는 기사 중 짧은 본문 우선, family·매체 다양성을 고려해 검토용 20개를 골랐다. 13개 family와 3개 매체를 모두 포함한다.

[comparison_001](comparison_001/summary.json)에 기사별 길이·인용 신호, 기사 쌍 9개, 문장 비교 후보 48개, 어절 후보 **6,645개**를 기록했다. 어절은 공백 분리 후보이며 형태소/POS·의미 청크 gold가 아니다. 원문 Unicode code point offset을 유지하고 NFKC는 별도 값과 해시로 저장했다. 문장·어절 원문 왕복은 통과했다.

비교 후보는 같은 잠정 family 안에서 규칙상 위치와 발화 유형이 같은 구간을 대상으로 문자 3-gram Jaccard 0.12 이상을 정렬하고, 문장을 재사용하지 않는 방식으로 기사 쌍당 최대 8개를 골랐다. 임계값은 검증되지 않은 검토 편의용 규칙이다. 같은 화자·주장·장르·scope를 확인했다는 의미가 아니므로 모든 후보의 `claim_relation=uncertain`, `style_comparison_eligible=false`를 유지했다. 공통 주장에 관한 포함/생략은 아직 확정하지 않았다.

HBM3E 12단 family의 두 기사에는 정규화 후 정확히 같은 문장 후보 5개, 인디애나 투자 family에는 1개가 있었다. 이 신호만으로 전재·보도자료 재작성 또는 독립성을 판정하지 않았다. 삼성 2024Q1 family 한 쌍은 현재 위치·발화 유형·유사도 규칙에서 후보 0개로 남겼다. 이를 공통 주장이 없다는 결론으로 바꾸지 않았다.

검토자는 [로컬 문장 비교 화면](comparison_001/raw/review.html)에서 48개 후보와 원문 위치·출처 링크를 나란히 볼 수 있다. 이 파일과 원문 JSONL은 Git 제외 경로에만 저장했다. 공개 CSV/index에는 본문 대신 식별자·해시·offset·후보 상태가 있다.

## 검증·보존과 변경 파일

수집기의 기존 strict 기본값을 유지하고 고정된 39개 후보용 `--research-authorization` 옵션을 추가했다. 출처·정확한 URL·candidate 제한, redirect별 출처/robots 재검사, 호스트 간격, 403·유료벽·429 처리, 새 경로 출력, 해시·URL provenance를 검증했다. 네트워크 없는 수집기 테스트 **34개 통과**. 두 실수집 manifest 감사도 각각 무결성 통과다.

추출기에는 tail·HTML comment·Unicode code point·XPath 왕복·시간 정밀도 회귀 확인을 수행했다. 비교·분류 결과는 저장 원문 해시/offset과 입력 ID를 다시 대조했다. 상세 결과는 [수집 독립 검증](validation_review.json), [비교 검증](comparison_001/validation.json), [기존 결과 보존 검증](preservation_validation.json), [최종 검증](final_validation.json)에 기록한다.

새 실행 결과는 `artifacts/p0/domestic_pilot_20260922/`에만 저장했다. 이전 실행 및 공식 원문은 보존했다. 변경 코드는 `scripts/p01_domestic_pilot.py`와 `tests/test_p01_domestic_pilot.py`, 추가 코드는 `scripts/p01_domestic_body_audit.py`, `scripts/p01_domestic_classify.py`, `scripts/p01_domestic_compare.py`다. 기존 `.gitignore`의 파일럿 raw 제외 규칙을 사용했다. 전체 파일 목록·해시는 [artifact_checksums.csv](artifact_checksums.csv), 실행 명령과 단계별 최종 경로는 [run_manifest.json](run_manifest.json)에 있다.

**이번 자동 실행은 수집·본문 위치 검증·규칙 분류·비교 후보 생성까지 완료했다.** 사람 두 명의 감사, 동일 주장 정렬, 독립 문체 판정은 완료되지 않았으므로 P01 전체 완료나 P02/P04 gold로 보고하지 않는다. 후속 100+20 기사 확대와 온톨로지는 실행하지 않았다.
