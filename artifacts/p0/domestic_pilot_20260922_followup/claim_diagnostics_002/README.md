# P01 주장 비교 준비 진단: 최종 002

기존 22개 기사·448개 문장 후보에서 규칙 신호 1,686개를 만들고 기존 비교 후보 48쌍을 보강했습니다. 이전 `claim_diagnostics_001`은 보존합니다. 독립 검토에서 발견한 소수 표기 동등성(1과 1.0), 개월/개수, 퍼센트포인트/퍼센트, 달력 날짜 유효성 경계를 보완한 결과가 이 디렉터리입니다.

| 신호 | 후보 수 |
|---|---:|
| 숫자·단위 | 381 |
| 기간 | 135 |
| 제품 | 345 |
| 회사·사업 범위 | 245 |
| 행위 | 249 |
| 계획·전망·발생 보고 단서 | 126 |
| 발화·화자 역할 단서 | 104 |
| 인용 경계 | 94 |
| 부정·불확실성 단서 | 7 |

48쌍 중 값·단위가 공통인 후보는 16쌍, 숫자·단위 집합이 다른 후보는 8쌍입니다. 후자는 모순 판정이 아닙니다. 값·단위와 명시적 기간·사업 범위·행위가 모두 공통인 후보는 보수적인 이번 규칙에서 0쌍입니다. **이는 실제 같은 주장의 기사 쌍이 없다는 뜻이 아닙니다.** 문맥이 여러 문장에 걸쳐 있거나 규칙이 근거를 놓친 경우를 포함해 사람이 검토해야 합니다. 48쌍 모두 기준 주장 연결·숫자의 의미상 수식 관계·화자 확인을 미완료로 유지합니다.

`claim_signals.jsonl`에는 정규화값·hash·Unicode codepoint offset·XPath와 같은 문장의 관련 신호 ID가 있습니다. `sentence_diagnostics.jsonl`은 모든 문장의 단서 목록과 혼재 상태를 담습니다. `pair_diagnostics.jsonl`은 공통 신호, 좌우에만 있는 신호, 준비 미완료 사유를 구분합니다. 같은 문장에 함께 나타났다는 연결은 의미상 수식 관계를 확정하지 않습니다. 원문 span은 Git에서 제외된 `raw/signal_spans.jsonl`에만 있습니다.

`validation.json`의 검증 23개가 통과했습니다. 원문 위치·hash, 참조 연결, 이전 입력 불변, 원문 저장 경계와 합성 반례를 확인했습니다. 001 대비 정규화 신호 7개가 바뀌었으며 48쌍의 진단과 집계는 그대로입니다. 규칙의 precision/recall, 원문 완전성, 실제 동일 주장이나 모순은 검증하지 않았습니다. 회사 이름은 사업 범위로 대체하지 않고, 상대 기간과 연도 없는 분기는 임의로 해소하지 않습니다. 복합 금액·범위·비교 기준·분모는 추가 검토가 필요합니다.
