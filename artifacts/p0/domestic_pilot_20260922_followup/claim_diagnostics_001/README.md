# P01 로컬 주장 비교 준비 진단

기존 기사 22개·문장 후보 448개에 규칙을 적용했습니다. 결과는 **신호 1,686개, 기존 문장 비교 후보 48쌍**입니다. 기사 내용이나 새로운 사실을 확정한 결과가 아니라, 사람이 같은 주장을 비교할 때 찾을 위치와 부족한 근거를 정리한 자료입니다.

| 신호 | 후보 수 |
|---|---:|
| 숫자·단위 | 381 |
| 기간 | 135 |
| 제품 | 345 |
| 회사·사업 범위 | 245 |
| 개발·검증·양산·공급/출하·판매·투자 행위 | 249 |
| 계획·전망·실제 발생을 보고하는 표현 | 126 |
| 발화·화자 역할 단서 | 104 |
| 인용 경계 | 94 |
| 부정·불확실성 단서 | 7 |

같은 값·단위가 잡힌 비교 후보는 16쌍입니다. 좌우 숫자·단위 집합이 다른 후보는 8쌍이며, 이 차이는 모순 판정이 아닙니다. 숫자·단위와 명시적 기간·사업 범위·행위가 동시에 공통으로 나타나는 후보는 0쌍입니다. 전체 48쌍에서 기준 발표의 주장 연결, 숫자가 무엇을 수식하는지 확인, 화자 확인과 사람 검토가 남아 있습니다.

- `claim_signals.jsonl`: 개별 신호의 정규화값·hash·Unicode codepoint offset·원본 XPath. 같은 문장의 기간/범위/제품/행위/양태/인용 신호 ID를 연결합니다.
- `sentence_diagnostics.jsonl`: 448개 문장 각각의 신호 목록과 계획/전망/발생 보고 단서의 혼재 상태. 화자 신원과 실제 사건 발생은 확정하지 않습니다.
- `pair_diagnostics.jsonl`: 48쌍의 공통 신호·왼쪽에만 있는 신호·오른쪽에만 있는 신호와 준비 미완료 사유. `claim_alignment_ready`는 모두 false입니다.
- `raw/signal_spans.jsonl`: 로컬 비공개 원문 span. 공개 출력에는 기사 문장·인용문·화자 이름을 복사하지 않습니다.
- `summary.json`, `validation.json`: 입력·스크립트 hash, 분모·분자, 기계적 검증 결과. 합성 반례와 실제 offset/hash·저장 경계 검사 19개가 통과했습니다.

동일 문장에 함께 등장했다는 연결은 의미상 수식 관계가 아닙니다. 회사 이름만으로 메모리/DS/전사 범위를 채우지 않고, 올해·전년·연도 없는 분기는 임의로 날짜를 부여하지 않습니다. 비트/바이트와 퍼센트/퍼센트포인트는 구분합니다. 복합 금액·범위·비교 기준·분모·숫자의 표기 차이는 추가 검토가 필요합니다. 규칙의 precision/recall과 원문 완전성은 검증하지 않았으며, 제품/범위 등 겹치는 신호가 있을 수 있습니다.

다시 실행할 때는 존재하지 않는 새 출력 디렉터리를 지정합니다. 기존 입력과 결과는 덮어쓰지 않습니다.

```powershell
python scripts/p01_domestic_claim_diagnostics.py --audit-dir artifacts/p0/domestic_pilot_20260922/body_audit_003 --comparison-dir artifacts/p0/domestic_pilot_20260922/comparison_001 --output-dir artifacts/p0/domestic_pilot_20260922_followup/claim_diagnostics_NEW
```

네트워크·LLM 호출은 없었습니다. 온톨로지와 학습/평가 gold는 만들지 않았습니다.
