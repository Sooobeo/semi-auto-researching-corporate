# 예약 소작업 자가검증 · 2026-10-06

- 후보 1개 / 문서 요청 1개 / HTTP 200·private 예약 1개. 직접 정책 요청 2개는 문서 분모와 분리했다. 공식 약관의 web 읽기는 정책 확인이며 후보 원문 읽기가 아니다.
- 요청 URL과 최종 URL이 동일하고 단일 호스트이며 실제 요청 시작 간격은 모두 2초 이상이다. 자동 redirect와 retry를 허용하지 않는다.
- 원문·robots·약관 저장 3개 / hash 재검사 3개 통과. Git 제외 확인. 문서 고지와 별도 permission notice 보존.
- 예약 상태는 `reserved_document_unlabeled`. 발행일 2025-10-29는 날짜만 있으며 정확 시각을 추정하지 않았다. 본문·수치·정답·학습 입력 노출은 없다.
- 완전 본문 수동 감사와 numeric parser 적응은 수행하지 않았다. 구조 존재 확인을 본문 완전성으로 승격하지 않았다. 비교열의 기존 주장 재등장·날짜 충돌·scope·수치 정확성은 후속 과제다.
- 개선: 성공뿐 아니라 preflight/문서 요청 실패에서도 `reservation_summary.json`을 만들도록 failure 경로를 보완했다. 약관 확인 실패의 권리는 `unresolved`로 남긴다. 기존 실행 파일 덮어쓰기를 차단하고 검증은 로컬 읽기와 append 기록만 수행한다.

이 결과는 단계1의 예약 소작업 완료이며 독립 인간 gold·미노출 test 검증 완료가 아니다.
