# P01 접근성 시험 범위 · 2026-10-05

사용자의 `structure 파악하고 p01,02 진행 후 브리핑해` 요청에 따른 신규 미국 자료 조사다. 현행 기준은 structure v1.2이며, 기존 한국기업 자료·결과는 입력·검증·평가에 사용하지 않았다. 이 범위는 agent가 선정한 접근 시험 후보이며 팀의 기업·기간·역할 합의가 아니다.

## 후보와 분석 질문

| 후보 | 범위 | 첫 질문 | 재무 개념 후보 |
| --- | --- | --- | --- |
| Microsoft | 공시 법인의 연결 전사; 사업부·Azure 제품 수치 별도 | 보고된 성장·수익성과 영업현금흐름의 기간·범위가 맞는가? | 기간 손익과 현금흐름, 설비투자 현금 지출 |

Microsoft·NVIDIA를 임시 후보로 제시해 사용자에게 선택 질문을 보냈으나, 본 실행 기록 작성 시 답변은 도착하지 않았다. 회계연도·분기 시작/종료일은 원자료 미확보로 미확인이다. 2024Q1~2026Q2 등 이전 한국 기간을 승계하지 않는다. 수집기 후보 정책은 2026-10-05까지 공개된 최신 10-K와 10-Q를 기업별 최대 1건씩 발견하는 소표본이며, 발견도 이번에는 미실행이다.

## 방법·역할·저장

- SEC 공식 조건과 발행사 이용조건을 먼저 확인한다. 원문 AI 입력·학습·외부 전송 조건은 별도 기록한다.
- 수집·정규화는 Python 표준 라이브러리의 로컬 deterministic 방법으로 준비했다. 원문 LLM 분석·모델 학습·유료 구매는 실행하지 않았다.
- 원문 허용 시 `raw/<run_id>/`, 블록과 비공개 본문은 Git 제외 위치에 보관한다. 이번 원문 저장은 0건이다.
- root는 실행·통합, 별도 agent는 조건 조사·P02 초안·재현 QA를 맡았다. 인간 담당·검토자·가용시간·개인 분석 추가 작업량은 미배정이다.
- agent 검토를 독립 인간 주석·일치도·gold나 개인 재무 이해의 증거로 계산하지 않는다.

## 제외·보류

한국기업 원문·registry·gold·모델·성능, 국내 뉴스 문체 quota, 기사 생성은 제외한다. 이번 미국 언론사 본문 후보는 0건이다. SEC 자동 접근 실패를 자료 부재로 해석하지 않는다. Microsoft IR의 코퍼스 조건과 NVIDIA IR 자동 수집 조건이 미확인/제한이므로 대체 크롤링을 보류했다.

기업 채택·기간·실제 회계범위·표본량·인간 담당·허용 오류·재무 적용 과제는 팀 확인이 남는다.
