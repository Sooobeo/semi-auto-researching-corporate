# 양식 사용성 시험 상태

2026-10-05 · 미완료. P02-T10은 두 명 이상의 팀원이 처음 보는 미국 실제 문서의 합의한 중복 표본을 설명 없이 독립 작성해야 한다. 현재 실제 근거 본문 0건·인간 독립 주석 0건·조정 0건이므로 완료로 표시하지 않는다.

합성 fixture로 구조·일부 의미 오류만 검사했고 schema_validation_report.json에 결과를 남겼다. 이는 작성자가 양식을 이해하는지, 실제 표/날짜/scope에서 일치하는지 검증하지 않는다. sample_annotations.jsonl을 빈 gold처럼 생성하지 않았다.

시험 전 기업·기간·새 문서·독립 작성자·조정자·노출 이력·가이드/registry hash를 고정한다. 질문이 나온 필드·원문 위치·답 공유 이전 기록·수정 전후를 남긴 뒤 가이드 버전을 갱신한다. 원문 부족·권리 미확인을 추정 사실로 채우지 않는다.
