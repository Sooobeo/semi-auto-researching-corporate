# 공통 학습 목표와 투자 리서치 적용 흐름

기준일: **2026-10-05 / 설계 v1.2**. [팀원의 개인 방향성 제안](../docs/project_direction/us_equity_research_proposal.md)과 사용자의 재무회계 학습·투자 리서치/기업 분석 목표를 함께 반영한 작업안입니다. 팀 전체의 역할 합의나 분석 수행 완료를 의미하지 않습니다.

[전체 설계](README.md) · [데이터 규약](DATA_CONTRACTS.md) · [결정 기록](DECISIONS.md) · [근거 자료](REFERENCES.md)

## 1. 목표의 관계와 범위

**공통 목표는 온톨로지와 NLP를 실제 미국 기업 자료에 적용해, 새 정보가 기존 상태를 어떻게 바꾸는지 근거와 함께 설명하는 것입니다.** 사용자는 같은 자료·검토 카드를 활용해 재무회계 개념을 이해하고 투자 리서치의 분석 과정을 수행하는 경험을 추가로 쌓습니다.

| 구분 | 목표 | 실제 수행을 남길 증거 |
| --- | --- | --- |
| 공통 · 온톨로지 | 개념·관계·비교 규칙을 직접 정의하고 실제 자료로 수정 | 정의·별칭·관계 등록부, 선택/제외 이유, 반례, 버전별 변경 이유 |
| 공통 · NLP | 기업·지표·사건·사업 관계·시점·조건을 추출하고 연결 | 원문 대조, baseline 비교, 오류 분류, 사람이 수정한 근거, 미노출 평가 |
| 공통 · 사업·시장 분석 | 제품·고객·경쟁·공급·산업 변화와 기존 전망의 관계를 설명 | 이전/새 주장과 관계, 대안 설명, 불확실성, 추가 확인 질문 |
| 개인 · 투자 리서치/기업 분석 | 재무제표·주석을 검토하고 실적·현금흐름·전망 변화를 해석 | 직접 작성한 비교표·계산·대사, 가정 변경 기록, 분석 메모, 동료 검토·수정 |

팀원 원문의 학습 우선순위와 직무 포트폴리오에 대한 선호는 그대로 유지합니다. 공통 프로젝트를 재무 비율 계산에만 한정하지 않으며 제품·고객·경쟁·공급·산업 관계와 비정량 사건도 분석 대상입니다. 필요한 관계 종류와 최초 표본은 실제 자료·질문·가용시간으로 정합니다.

공통 결과물은 **근거가 연결된 검토 카드와 배치·로컬 MVP**입니다. 분석 메모는 기존 카드·근거·계산을 재사용하는 개인 적용 산출물로 둡니다. 모든 팀원에게 재무 모델·분석 메모·직무 포트폴리오 작성을 요구하지 않습니다. 별도 화면이나 웹서비스를 추가하지 않고 파일과 카드 참조로 시작합니다.

역할은 온톨로지/NLP 담당과 재무 분석 담당을 고정된 사람·인원에 대응시키지 않습니다. 개인 목표의 담당·검토자·추가 작업량은 팀 분담 시 기록하고, 공통 기능·검증에 필요한 작업과 개인 확장 작업을 구분합니다.

## 2. 하나의 사례를 함께 사용하는 방법

아래는 실제 기업 발표가 아닌 설명용 사례입니다.

```text
기존 정보: 기업 A의 제품이 고객 B와의 계약을 바탕으로 판매될 계획
새 정보:   A가 해당 계약의 축소를 발표

공통 작업: 기업·제품·고객 관계, 계약 변경, 적용 시점, 조건·근거 추출
           → 이전 관계·계획과 비교 → 원문 검증 → 검토 카드
개인 적용: 관련 매출 범위·회계정책·실적·현금흐름 확인
           → 전망 가정 유지/수정/보류 → 분석 메모와 검토 기록
```

공개된 계약 금액·제품 매출이 없다면 재무 영향 규모는 계산 불가로 남깁니다. 재무 수치가 없어도 사업 관계 변화의 중요성이 낮아지는 것은 아닙니다. 관계의 원문 주장, 재무 영향 해석, 추가 가정에 따른 계산을 별도 층에 기록합니다.

## 3. 투자 리서치 적용 순서

다음 순서는 CFA Institute의 공개 재무제표 분석 프레임워크를 프로젝트에 맞게 적용한 설계입니다. 목적 설정·자료 확보·처리·해석·보고·후속 갱신을 연결하되, 공개 기업 자료로 수행할 수 있는 범위만 다룹니다. [FIN01](REFERENCES.md)

| 순서 | 사람이 수행할 분석 | 공통 시스템의 지원 | 남길 기록·관련 작업 |
| --- | --- | --- | --- |
| 1. 질문·기준 시점 설정 | 기존 사업 가정과 확인할 재무 질문, 분석 시점 명시 | 기업·scope·기간·공개 시점 제한 | `scope.md`, 분석 질문 · P01-T01/P02-T09 |
| 2. 기준 자료 검토 | 해당 기업의 연차/중간 재무제표, 주석, 경영진 설명, 실적 발표 확인 | 문서·표·주장·사업 관계의 위치 연결 | manifest·추출 감사 · P01-T04/T07 |
| 3. 비교표·계산 작성 | 기존·새 실적의 기준을 맞추고 수작업 표본 계산·대사 | 단위·기간·정의 정규화, prior 검색, 수식 실행 | concept catalog·reconciliation · P03-T05/P07-T09 |
| 4. 실적·사업 변화 해석 | 성장·수익성·현금흐름·재무상태를 사업 변화와 연결, 대안 설명 검토 | 지표 변화와 제품·고객·경쟁·공급 관계를 함께 제시 | 카드의 판단 근거·미확인 사항 · P06/P07 |
| 5. 전망·가정 재검토 | 회사 가이던스와 자신의 추정·가정을 구분하고 유지/수정/보류 | 동일 미래 기간의 가정·시나리오 버전 비교 | `research_assumptions.jsonl`, scenario · P07-T11 |
| 6. 분석 메모 작성·검토 | 결론·반대 근거·한계·다음 확인 사항을 작성하고 수정 | 카드·원문·계산·가정 ID 연결 | `analyst_memos.jsonl`, feedback · P08-T04/T06 |
| 7. 후속 정보로 갱신 | 새 발표를 받은 뒤 이전 메모·가정과 비교 | as-of 검색과 변경 이력 보존 | 메모 revision·수행 기록 · P08-T11/P09-T11 |

검토 카드는 사업 사건·관계 변화만으로도 만들 수 있습니다. 개인 적용 사례는 재무 분석에 필요한 자료가 있는 표본 중 선정합니다. 메모·수작업 연습에 사용한 사례는 exposure를 기록하고 독립 test로 재사용하지 않습니다.

## 4. 재무회계 개념과 지표 후보

아래는 초기 **선정 후보**이며 전 기업·전 섹터 공통 필수 목록이나 확정 가중치가 아닙니다. 최초에는 실제 공개 자료로 계산·설명·교차검증할 수 있는 개념 일부를 선정하고 나머지는 보류 이유를 기록합니다. 금융업 등 업종별 구조 차이는 별도 정의가 필요합니다. 재무제표의 구성과 현금흐름·주석의 연결은 SEC 입문 자료를 출발점으로 삼습니다. [FIN03](REFERENCES.md)

| 개념 | 관찰·계산 후보 | 이해를 설명할 질문과 검증 |
| --- | --- | --- |
| 발생주의와 현금흐름 | 순이익, 영업현금흐름(CFO), 비현금·운전자본 조정 | 이익과 현금이 왜 달라졌는가? 원문 대사 항목으로 설명하며 차이만으로 회계 부정 판정 금지 |
| 성장과 수익성 | 매출, 매출총이익·영업이익, 각 이익/매출의 마진 | 매출 증가가 이익 증가로 연결됐는가? 동일 scope·기간·회계기준과 양의 매출 분모 확인 |
| 운전자본과 회수·지급 | 매출채권·재고·매입채무, 기간별 잔액 변화, 현금흐름표 조정 | 회수·재고·지급 변화가 CFO와 어떤 관계인가? 잔액 차이를 환율·인수 등 확인 없이 CFO 항목과 동일시 금지 |
| 설비투자와 감가상각 | 현금 설비투자, 감가상각·상각, CFO, 프로젝트 정의 FCF | 현금 지출과 비용 인식이 어떻게 다른가? 취득 범위·부호·기간을 확인하고 현금 지출 전부를 당기 비용으로 처리 금지 |
| GAAP와 회사 조정지표 | GAAP 실적, 회사 non-GAAP 지표, 개별 조정·세금 항목 | 무엇을 조정했고 반복 가능성·비교 가능성은 어떤가? 동일 지표명이 동일 정의라는 가정 금지 |
| 유동성과 차입 부담 | 현금·현금성자산, 유동자산/부채, 차입금·만기·이자 관련 주석 | 단기 지급·차입 부담이 어떻게 바뀌었는가? 부채 전부를 이자부 차입금으로 분류하거나 공시 없는 만기 추정 금지 |

`프로젝트 FCF = CFO - 현금 설비투자 지출`을 채택하면 지출을 양의 금액으로 정규화하고 정확한 포함 범위·수식 버전을 등록합니다. 회사 발표 FCF는 회사 정의를 별도 metric으로 보존합니다. SEC는 FCF에 통일된 정의가 없음을 설명하므로 둘을 자동으로 합치거나 자유롭게 쓸 수 있는 잔여 현금으로 해석하지 않습니다. [FIN04](REFERENCES.md)

ROE/ROIC·회전일수·EPS 분석·밸류에이션 등은 질문·분모·회계정책·필수 입력이 정해진 경우 후속 후보로 둡니다. 전면적인 3개 재무제표 전망 모델·DCF·목표주가·매매 판단은 초기 필수 산출물로 추가하지 않습니다. 기준 업무는 공개 자료에 근거한 기업 분석이며 내부 장부·결산 업무를 수행했다고 표현하지 않습니다.

## 5. 중요성 판단과 전망의 경계

agent는 공개 시점에 이용 가능했던 근거로 **검토 필요성과 이유**를 보조합니다. 재무·사업 변화의 후보 판단 축은 다음과 같습니다.

- 수익성·현금 창출·유동성·차입 부담의 변화.
- 제품·고객·경쟁·공급·산업 구조와 기존 사업 가정의 변화.
- 이전 전망·가정의 재검토 필요성, 변화의 규모·지속 가능성·적용 시점.
- 비교 가능성·근거 충분성·미공개 항목과 다음 검토 행동.

재무 영향이 아직 계산되지 않은 사업 사건도 보존합니다. 금액 크기나 좋은/나쁜 방향만으로 중요성을 확정하지 않고, 다차원 질문·검토 행동 라벨을 실제 표본에서 비교합니다. 가중치·임계값·합산 여부는 P04/P06의 독립 검토와 dev 결과로 정하며 미래 실적·사후 주가를 과거 판단에 넣지 않습니다.

전망 기록에는 회사가 발표한 가이던스, 사람이 작성한 분석 가정, 공식에 따른 파생 전망을 구분합니다. 이전/새 추정 비교는 같은 미래 대상 기간·scope·정의를 대상으로 하고 근거·가정이 부족하면 보류합니다. low/base/high는 명시한 가정 집합이며 통계적 신뢰구간이 아닙니다.

## 6. 사람과 agent의 역할·학습 증거

| 사람의 책임 | agent가 보조할 작업 | 반드시 남길 증거 |
| --- | --- | --- |
| 개념·관계·공식 정의, 분석 질문 선정 | 후보 표현·별칭·필드 제안 | 채택/제외 이유와 반례, 담당자·검토자 |
| 원문 확인과 표본 수작업 계산 | 숫자·표·관계 추출, 정규화·수식 실행 | 원문 위치, 직접 계산 시점, 모델 출력 열람 여부, 대사·수정 기록 |
| 사업·재무 해석, 반대 근거와 가정 결정 | 변화 목록·추가 확인 질문·메모 초안 | 사람이 채택/수정/보류한 이유, 대안 설명, 미확인 사항 |
| 독립 검토·성과 설명 | 오류 후보와 재현 자료 정리 | 조정 전 개별 기록, 검토 의견, 수정 전후와 실제 기여 |

각 참여자의 `learning_cases.jsonl`에는 온톨로지·NLP·사업 분석·재무회계 중 실제 수행 영역을 기록합니다. 재무 분석 담당은 직접 확인한 원문·수작업 계산·해석·가정 수정·분석 메모를 설명할 수 있어야 합니다. 다른 참여자는 실제 맡은 정의·추출·오류 개선·검증 내용을 남깁니다. 공통 경험과 개인 경험을 같은 사례에 연결하되 다른 사람의 기여를 자신의 수행으로 표시하지 않습니다.

학습 사례는 자동으로 gold가 되지 않습니다. 독립 annotation·조정 절차를 거친 평가 레코드와 구별하고, agent 초안만 존재하는 사례는 본인의 개념 이해·직무 프로세스 수행 완료로 보고하지 않습니다.

## 7. 평가와 착수 순서

**공통 평가:** 온톨로지 정의·관계·비교 규칙의 적용 및 수정 근거, NLP 추출/연결 정확도·오류 개선, 사업·시장 해석의 근거·불확실성, 검토 카드의 효용·시간·비용을 평가합니다. 사람 간 일치도와 시스템 정확도는 따로 보고합니다.

**개인 적용 평가:** 선정 재무 개념의 설명, 원문·단위·기간 대조, 수식·계산·대사, 사업 변화와 재무 영향의 연결 및 대안 설명, 가정·메모의 수정 이력을 동료가 검토합니다. 해석은 논리·근거 적절성으로 평가하고 수치 계산의 정답 검증과 구별합니다. 개인 적용의 미완료를 공통 시스템의 성능 실패로 합산하지 않으며 별도로 보고합니다. 투자 수익률 개선은 필수 KPI가 아닙니다.

1. P01에서 기업·자료·기간·변화 질문과 역할을 정하고, 사업 관계 사례와 재무 적용 후보의 자료 접근성을 함께 확인합니다.
2. P02/P03에서 공통 개념·관계에 선정 재무 개념·계산 규칙을 연결합니다. 재무 지표만으로 표본을 편중시키지 않습니다.
3. P04/P05에서 사실·관계의 독립 주석과 NLP 검증을 수행합니다. 개인 연습·정의 수정 표본의 노출을 기록합니다.
4. P06/P07에서 사업·재무 변화의 검토 필요성, 과거 상태 비교·대사·가정 갱신을 구현합니다.
5. P08/P09에서 동일 근거의 검토 카드·선정 개인 메모를 연결하고, 공통 성능과 개인 수행 증거를 각각 보고합니다.

기업·기간·최초 재무 개념·사례 수·역할·추가 작업량·허용 오류는 아직 미정입니다. 기존 한국기업 자료·결과를 사용하지 않고 새 미국 표본으로 확인합니다. 이 문서는 실행할 설계이며 재무 분석·학습 성과가 이미 달성됐다는 기록이 아닙니다.
