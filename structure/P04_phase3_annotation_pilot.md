## 1. 이 단계에서 답할 질문

100~300개 독립 사건을 두 사람 이상이 일관되게 기록할 수 있으며, 학습·검증·평가를 누수 없이 분리할 수 있는가?

- **책임 역할:** C 데이터·분할·조정, A/B 독립 annotation. C의 작성본은 A/B가 검토
- **착수 조건:** P1 가이드와 P2 registry 버전 고정. P2 전이용 사례는 adaptation으로 이미 노출되었다는 이력을 유지.
- **범위:** 100~300건 사건 gold v1, 라벨 가이드, 일치도·모호성·분할 manifest. 문서100개와 사건100개는 다르다.
- **연결 에픽:** [KAN-7](https://qyurimoon.atlassian.net/browse/KAN-7). 실명·기한은 팀이 배정하며 여기서는 역할 기준으로 작성합니다.

## 3. 상세 설계와 판단 규칙

### 표본 구성과 규모

100~300건은 초기 파일럿 규모이며 고성능 모델 학습을 보장하지 않는다. 실적·계획·실행·정정·부인·반복·정성 변화·무관 문서도 포함한다. rare 유형을 추가 표집했다면 자연 발생 비율과 다르다는 점을 명시한다. 관련성 분류를 평가하려면 사건이 있는 문서만 모아서는 안 되므로 무관/관련 문서 라벨도 별도로 만든다.

### 중복 평가와 역할

v1 권장 운영은 모든 파일럿 사건을 A/B가 독립 작성하고 C가 불일치를 조정하는 방식이다. 부담이 크면 최소 중복 비율을 작업 시작 전에 정하고 유형·기업·기간별 층화 표본을 확보한다. 단독 라벨 자료는 단독 작성임을 표시하며 합의 gold처럼 취급하지 않는다. 연습용10~20건은 훈련용 가이드 개발에 쓰고 untouched test에 넣지 않는다.

### 시간·사건 그룹·기업 분리

chronological split의 날짜 경계는 실제 자료 분포를 보고 고정한다. 출처 번역본·재보도·정정 관계를 포함한 이벤트 family가 경계를 가로지르면 한쪽으로 이동하거나 boundary embargo 세트로 빼고 이유를 기록한다. 같은 사건을 훈련과 평가에 넣지 않는다. 학습 이후 발생한 prior-state 사실을 검색용 읽기 전용 기록에 추가할 수는 있지만, 해당 시점까지 공개된 원문만 쓴다. 평가 정답·수정 피드백을 학습하는 것과 구분한다.

리노공업·ISC 중 P2에서 읽은 사례는 adaptation이다. 회사 자체가 완전히 미노출이라고 주장할 수 없다. 후속 미사용 기간·사건으로 post-adaptation test를 만들고, 정말 미노출 기업 평가가 필요하면 다른 기업을 별도 선정한다. 기업2개로 Leave-one-company-out 결과가 있어도 산업 전체 일반화의 증거는 제한적이다.

### 라벨과 일치도

기업·숫자·단위·기간은 exact match, span은 offset F1, 유형/등급은 해당 척도에 맞는 일치도와 혼동표를 사용한다. [R03](REFERENCES.md)을 읽고 nominal/ordinal 계수를 구별한다. 조정 후 값끼리 비교해 일치도를 부풀리지 않는다. unknown과 not_applicable을 제외하면 제외 건수·분모를 보고한다.

### 평가자의 정보 제한

발표 시점에 존재한 자료만 평가 화면에 제공하고 이후 주가·정정·후속 실행은 감춘다. 시장 outcome은 별도 테이블로 분리한다. 자기 기억으로 알게 된 사후 정보를 완전히 제거할 수 없으면 한계로 기록한다. 중요성 ‘판단 불가’를 무시 라벨로 바꾸지 않는다.
