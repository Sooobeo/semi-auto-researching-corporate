## 1. 이 단계에서 답할 질문

같은 기간의 실제 공시·IR을 재현 가능하게 확보하고, 사건과 수치를 원문 위치까지 추적할 수 있는가?

- **책임 역할:** C 기준·통합, A 삼성 메모리, B SK하이닉스
- **착수 조건:** 최신 기업 선정 계획과 로컬 저장소 접근. API 키가 없어도 공식 페이지 수동 접근 시험부터 수행한다.
- **범위:** 최초 6개 문서 접근 시험에서 시작하여 기업별 2024Q1~2026Q2의 10개 분기 목록으로 확장한다. 수집기 전체 서비스·NLP 모델 학습은 P4 이후다.
- **연결 에픽:** [KAN-4](https://qyurimoon.atlassian.net/browse/KAN-4). 실명·기한은 팀이 배정하며 여기서는 역할 기준으로 작성합니다.

## 3. 상세 설계와 판단 규칙

### 기업과 문서 선정

A는 삼성 메모리 사업에 해당하는 문장·표를 추출하되 원문 전체의 DS·다른 사업 섹션은 문서 맥락으로 보존한다. B는 SK하이닉스 연결·제품 범위를 확인한다. 회사별 10개 분기 × 자료 종류 표를 먼저 만들고 빈칸을 찾는다. IR이 없는 칸을 다른 종류로 대체하면 대체 사유를 기록한다.

연속 2개 분기 IR와 사업보고서 1개씩 총 6개를 최초 시험한다. 삼성은 [C01/C02](REFERENCES.md)로 계획→후속 실행을 확인한다. 이 6개만으로 전 기간 접근성이 검증됐다고 쓰지 않는다. 연차보고서와 분기 IR의 대상 기간·발표일은 다르다.

### 수집 성공과 본문 추출 성공

화면 열림, 파일 저장, 본문 추출, 표 의미 보존은 서로 다른 열이다. HTTP 200이나 파일 존재만으로 성공 처리하지 않는다. HTML 오류 페이지가 PDF 이름으로 저장되는 경우 MIME·파일 시그니처·페이지 수를 점검한다. 수동 복사 성공을 자동 추출 성공에 포함하지 않는다.

### 문서 ID·버전

문서는 stable doc_id, 다운로드본은 revision_id로 분리한다. 같은 파일 hash는 재수집 로그만 추가한다. 정정 자료는 원문을 덮어쓰지 않고 supersedes_doc_id와 공개시점을 기록한다. 한국어·영어 번역본은 개별 문서이되 같은 발표 그룹을 연결한다. exact duplicate와 같은 사건의 후속 발표는 다르다.

### 최소 저장 체계

원문 보관이 허용되면 artifacts/p0/raw 아래 보관하고 manifest에서 연결한다. 제한된 원문은 공유 폴더나 Git에 복제하지 않고 URL·허용된 근거·권한 조건을 남긴다. API 키는 환경 변수로 받고 로그·manifest에 기록하지 않는다. Git에는 설계·수집 코드·공개 가능한 샘플만 넣는다.

### 품질 지표의 분모

접근률=실제 본문을 읽은 고유 문서/접근을 시도한 고유 문서. 자동 추출률=지정 파서가 usable text를 만든 문서/자동 추출 시도 문서. 중복률=중복 판정 다운로드 건/전체 다운로드 건이며 고유 문서 접근률과 분모를 섞지 않는다. 시각 정확도는 정확 시각/날짜만/미상으로 분포를 보고한다. 실패 원인은 권한·파일손상·동적 페이지·OCR 필요·원문 누락·도구 제한으로 분리한다.

## 5. 필수 검증 시나리오

- [ ] 동일 파일 재수집 시 doc_id가 늘지 않는다.
- [ ] 연도·분기 열이 섞인 표를 자동 QoQ 비교 대상으로 넘기지 않는다.
- [ ] 공식 페이지 열기 실패는 기업 자료 부재로 기록하지 않는다.
- [ ] 날짜만 있는 발표는 임의로 00:00의 정확 시각이라고 표시하지 않는다.

## 6. 단계 종료와 다음 단계 전달

**종료 기준:** 고유 문서 목록·원문 위치·실패 및 이용조건이 모두 연결되고 다른 팀원이 실제 문서와 숫자표를 재확인했다. 목표 성공률 수치는 파일럿 결과를 보고 결정 기록에 남기며 달성한 것처럼 미리 기입하지 않는다.

**인계:** P1/P2에 자료와 예외를 전달한다. 품질 불량 형식은 P4 학습에 넣기 전에 보완 또는 제외 근거를 남긴다.

결과 기록에는 완료 작업 ID, 산출물 경로·버전·hash, 실제 건수, 검증 결과, 검토 역할, 남은 문제와 후속 작업을 남깁니다. 미실행 검증을 통과로 표시하지 않습니다. 성능 목표·예산·표본 수 변경은 [결정 기록](DECISIONS.md)에 남깁니다.
